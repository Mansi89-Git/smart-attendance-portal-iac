# Smart Attendance and Leave Portal

## Project
Smart Attendance and Leave Portal using Serverless Application

## IaC Tool
AWS CloudFormation

## AWS Resources
- Amazon S3
- Amazon DynamoDB
- AWS IAM

## DynamoDB Tables
- SmartAttendance-Users
- SmartAttendance-Attendance
- SmartAttendance-LeaveRequests

## Purpose
CloudFormation is used to provision and manage the cloud infrastructure required for the Smart Attendance and Leave Portal.
